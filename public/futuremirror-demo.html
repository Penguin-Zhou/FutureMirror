query_course_catalog

为什么是「AI Native」而不是「套壳题库」

🤖多 Agent 协作

面试官按轮次与模式轮转，基于回答动态追问；观察员实时记录证据，教练生成学习路径——追问策略由 LLM 决策，而非固定题库。演示版将规划、工具调用、证据记录的结构完整呈现。

📖RAG 混合检索

BM25 词面召回 + 端侧向量（MiniLM 384 维，Transformers.js 浏览器内计算）语义召回，两路归一分后加权融合，答案必须标注来源与两路得分，资料不足时明说「暂无相关资料」。完整版为 pgvector + RRF + Rerank。

📊可解释评分

五个维度分数全部引用对话原话作为证据——演示版中每条证据均来自你的真实回答；完整版另建校准样本集量化评分一致性。

🎙️多模态交互

演示版已集成浏览器原生能力：语音输入（Web Speech API）、TTS 朗读（speechSynthesis）、简历文件上传。完整版叠加 Whisper ASR、语速/停顿分析与白板代码理解。

🔒隐私优先

本地 PII 脱敏（身份证/手机号/邮箱）+ Prompt 注入检测，原始简历不上云；演示版 API Key 仅存 sessionStorage，关闭即清除；脱敏顺序经过单元测试验证。

⚡三级兜底

无 API Key 自动 Mock；模型超时/限流自动降级本地流式输出；API 失败时启发式算法兜底——演示现场不翻车。

技术架构

用户浏览器→ Next.js 15 前端→ Route Handlers→ Agent 编排层→ 多模型路由（免费额度优先）

技术栈：Next.js 15 App Router · React 19 · TypeScript · Tailwind CSS v4 · Zustand · Recharts · Zod · Vitest。
AI 层：版本化 Prompt（prompts/*.md）· Zod 约束输出 · 流式 SSE · 自动降级 · PII 脱敏 · 注入检测。
本演示页即完整项目的 /demo 页：在线部署时连接真实后端（LLM 流式 / JWT / 服务端评分），离线时 Mock 逻辑与 lib/ai 降级链路保持一致。

向量索引未初始化

检索层为 BM25 + 端侧向量混合检索：BM25（k1=1.5 / b=0.75，中文 bigram 切分，标题字段加权）× 0.4 + 余弦相似度 × 0.6，两路各自归一分后融合。
向量由 Transformers.js 在浏览器内计算（all-MiniLM-L6-v2，384 维，40 条面经向量预计算后写入 localStorage），不需要后端、不需要 API、离线可跑；无模型文件时自动降级为 n-gram hashing 向量（256 维），检索链路不中断。完整版技术方案为 pgvector + RRF + Rerank。

⚠️ 已知边界与限制

本演示页支持在线（真实后端）与本地（单文件离线）两种运行形态，以下为诚实的边界说明，完整工程见代码仓库。

演示页为单文件静态页，双形态运行：在线部署时连接真实后端（真实 LLM 流式 / JWT 登录 / 服务端评分落库）；本地打开时全部逻辑（断言、MCP 工具、Mock 降级）在浏览器内执行，无后端依赖。完整 Next.js 工程另含 pgvector 混合检索与多模型路由。
本地单文件版登录为演示级：密码仅做本地简单混淆存储，不应用于生产；在线演示已切换为真实后端 JWT 登录与会话持久化。完整工程采用 NextAuth + Postgres + 密码哈希。
向量库双形态：本地单文件版用浏览器内单机索引（localStorage 存 40 条面经向量，MiniLM 384 维，混合打分在浏览器内完成）；在线版由服务端混合检索 + 五特征重排提供。完整工程升级为 pgvector 持久化 + RRF 融合 + Cross-Encoder Rerank。
代码沙盒为浏览器 Worker 隔离：具备 2s 超时熔断，仅支持纯 JS 逻辑题；完整工程集成 QuickJS WASM 沙盒，支持多语言与虚拟文件系统。
MCP 为本地模拟 Server：协议结构与真实 MCP 一致，完整工程通过 @mcp-b/webmcp-ts-sdk 实现跨 Agent 真实发现。
演示视频录制中：代码仓库 / 技术文档 / 在线演示地址均已就位（见本页「交付材料」区块），演示视频成片后补入。
