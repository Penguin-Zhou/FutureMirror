## 摘要

面镜 FutureMirror 面向"面试准备缺乏真实对手、反馈不可解释、改进无路径"三个痛点，用**多 Agent 圆桌协作**替代单人问答：HR、技术、压力面、观察员、教练五个角色按规则轮转分工，围绕用户上传的简历与目标岗位 JD 展开多轮模拟面试，全过程**流式打字**呈现。

系统产出三类结果：**可解释的评分报告**（五维分数 + 逐条点评 + 回答原文摘录取证）、**能力雷达可视化**、**按最弱维度排序的 Day-N 改进计划**。配套题库小测、错题本、求职看板与 AI 小助手形成"练习—评估—补强—再评估"闭环。

工程上的取舍集中在两点：**演示必须零依赖可跑**（单文件 493KB，CSS/JS 全内联，默认零外部请求，断网不断演练），以及**评分必须可核对**（每个分数都能追到具体一轮回答的原话与计算因子）。为此设计了"单文件演示版 ↔ 模块版前端"的双向机械转换（逐字节等价）、"后端真实模型 → 浏览器直连 Key → 本地 Mock"的三级降级，以及全部运行在浏览器内的 BM25 + 端侧向量混合检索。

## 1. 项目概述与目标

### 1.1 我们要解决的问题

面试准备存在三个长期存在但难以自助解决的问题：

| 问题 | 现状 | 面镜的做法 |
| --- | --- | --- |
| **没有真实对手** | 背模板、看面经，缺乏追问压力；真人模拟成本高、难以反复 | 五个 Agent 分工协作：追问、施压、观察、复盘都由不同角色承担，可无限次重跑 |
| **反馈不可解释** | 打分类产品只给总分或几句话点评，不知道扣分在哪 | 五维分数每条都附带**计算依据**（量词数、STAR 词、口头禅、技能命中、防御性表述）与**原话摘录取证** |
| **改进行动缺方法** | "多练表达"这类建议无法落地 | 按最弱三个维度自动分配 3/2/1 项任务，生成带日期的 Day-N 学习路径 |
| **演示环境不可控** | 依赖云 API 的产品在赛场网络不稳时直接白屏 | 三级降级：后端真实模型 → 浏览器直连 Key → 本地 Mock；断网也能完整走完流程 |

### 1.2 目标用户

- **求职者 / 应届生（终端用户）**：需要低成本、高频次的模拟面试与可执行的改进计划。
- **评委与开发者（演示态）**：需要在不装环境、无网络、无 Key 的情况下，3 分钟内看懂系统做了什么、怎么做的。

### 1.3 功能清单

| 编号 | 模块 | 能力 |
| --- | --- | --- |
| 1 | 简历—岗位匹配 | 解析简历文本与目标 JD，输出匹配度、命中技能、能力缺口（本地规则计算，无外部依赖） |
| 2 | 多 Agent 模拟面试 | 五角色追问 / 压力面 / 连环追问，流式打字输出，支持中途停止与重开 |
| 3 | 代码沙箱 | 内置算法题，浏览器内 JS 沙箱执行用例，结果计入"内容深度"维度 |
| 4 | 可解释评分报告 | 五维打分 + 雷达图 + 逐维点评 + 最近 4 轮原话取证 + `weakest` 最弱维度 |
| 5 | 学习路径 | 基于最弱三维按 3/2/1 配额生成 Day-N 任务清单 |
| 6 | 题库小测 | 单选 / 多选 / 判断，支持计时、VIP 不限次、错题自动入库 |
| 7 | 错题本 | 按标签归类，支持重做与掌握度标记 |
| 8 | 求职看板 | 岗位线索拖拽流转（意向 → 投递 → 面试 → offer） |
| 9 | AI 小助手 | 基于本地知识库回答，引用可点击查看来源条目 |
| 10 | 开发者模式 | 运行环境检测、性能指标、工程自检、MCP 运行时证据、技术架构图、诊断日志导出 |
| 11 | Prompt 查看器 | 展示各 Agent 的版本化 Prompt，便于核对产出差异 |
| 12 | 三级降级容错 | 后端 5xx / 超时 / 无 Key 自动回退，页面顶部如实显示当前 LLM 模式 |

### 1.4 交付形态

同一套业务逻辑共有四种落地形态，按演示场景选择其一即可：

| 形态 | 位置 | 定位 |
| --- | --- | --- |
| **单文件演示版** | `public/futuremirror-demo.html` | 零安装、可离线；约 493KB，CSS/JS 全内联，默认零外部请求 |
| **模块版前端** | `frontend/` | 由单文件版按"版本横幅"机械拆出的 27 个 JS 模块 + 3 层 CSS，行为与单文件版逐字节等价 |
| **FastAPI 后端** | `backend/` | 演示版的可选后端：JWT 鉴权、SQLite 持久化、GLM SSE 流式代理（API Key 只存服务端环境变量）、服务端评分落库 |
| **Next.js 完整版** | `app/` `lib/` `components/` | 生产形态全栈应用：Route Handlers + 多模型路由 + RAG + Zod 契约 + Mock 兜底 |
